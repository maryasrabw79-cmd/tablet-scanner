# أداة ياسر الدقاق لتسجيل أرقام التابلت

تطبيق ويب مستقل بواجهة عربية لتسجيل باركود الجهاز ورقم S/N، مع جدول ومراجعة وتصدير Excel أو CSV.

## التشغيل
- انشر المستودع باستخدام GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).
- افتح رابط GitHub Pages من الهاتف عبر HTTPS.
- اضغط «تشغيل الكاميرا» واسمح بالوصول إلى الكاميرا الخلفية.
- عند اكتشاف الباركود، تتوقف الكاميرا وتحاول الأداة قراءة رقم S/N من الصورة. راجع الرقم يدويًا قبل الحفظ لأن OCR قد يخطئ مع الأرقام الصغيرة.
- إذا لم يدعم المتصفح BarcodeDetector، أدخل الباركود يدويًا.

## البيانات والخصوصية
السجلات محفوظة محليًا في المتصفح على الجهاز باستخدام localStorage. لا يوجد خادم يجمع البيانات. صدّر Excel أو نسخة JSON احتياطية بانتظام. مسح بيانات المتصفح قد يؤدي إلى فقد السجلات.

## ملاحظات تقنية
- يتطلب تشغيل الكاميرا سياقًا آمنًا HTTPS أو localhost.
- قراءة الباركود تعتمد على BarcodeDetector في المتصفح.
- قراءة النص تستخدم Tesseract.js، وتصدير XLSX يستخدم SheetJS عبر CDN؛ يلزم اتصال بالإنترنت لتحميل المكتبات الخارجية.
- يمكن استخدام تصدير CSV إذا لم تتوفر مكتبة XLSX.
